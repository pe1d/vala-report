# adapters/

Thư mục MẪU KHỞI TẠO adapter. Lần chạy đầu, nếu một hệ thống nguồn trong CSDL chưa có
`adapter_yaml`/`auth_profile`, SourceRegistry sẽ chép file `*.yaml` ở đây vào CSDL.

Hiện để trống: adapter/hệ thống nguồn được **cấu hình hoàn toàn trên giao diện**
("Hệ thống nguồn" → Adapter). Không seed egov/etask trong code nữa.
